# 🍔 Flutter Food App

A simple food ordering app built using Flutter and basic concepts.

---

## 📱 Screens

* 🏠 Home Screen
* 🍔 Food Details Screen
* ❤️ Favorites Screen
* 👤 Profile Screen

## ⚙️ Features

* Display food items in grid layout
* Navigate between screens
* Clickable buttons (print actions in terminal)
* Simple and clean UI
* Basic Flutter widgets only

---

## 🛠️ Technologies

* Flutter
* Dart
* Material Design

---

## 🚀 How to Run

git clone https://github.com/AmrElnegry/Task_Flutter_Cis.git
cd Task_Flutter_Cis
flutter run

---

## 📂 Project Structure

* "lib/main.dart" → main app code
* "lib/" → screens and UI
* "assets/" → images
